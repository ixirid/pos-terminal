# 🚀 Virtual POS & Payment Display System

Полнофункциональная система виртуального кассового терминала, дисплеев покупателя и веб-эквайринга с синхронизацией данных в реальном времени через WebSockets и файловым хранилищем.

---

## 🌟 Ключевые возможности

### 💻 Кассовый терминал кассира (`/`)
* **Интерактивный ввод суммы:** Физический нумпад на экране, кнопки быстрого выбора (+100 ₽, +500 ₽, +1000 ₽) и ручной ввод.
* **Поддержка физической клавиатуры:** Управление с помощью клавиш (`Enter` — подтверждение, `Esc` — сброс/отмена, цифры, `Backspace`).
* **Таргетирование дисплеев:** Возможность отправить QR-код на конкретный экран покупателя или на все подключенные устройства сразу.
* **Звуковые эффекты и анимации:** Полноэкранные модальные окна успеха/ошибки со звуковым сопровождением транзакций.

### 📺 Интерактивные дисплеи покупателя (`/display`)
* **Авто-регистрация:** Подключённые устройства автоматически регистрируются в системе с уникальным ID и IP-адресом.
* **Реалтайм-отображение:** Мгновенный вывод QR-кода на оплату, сумма заказа и статус транзакции.
* **Удалённый контроль:** Возможность блокировки/разблокировки конкретного дисплея с кассового терминала.

### 📱 Страница оплаты и Эквайринг (`/pay`)
* **Оплата по QR-коду:** Генерация динамических QR-кодов с автоматическим определением внешнего хоста (поддержка Render HTTPS).
* **Клиентский портал (`/client`):** Интерфейс для проверки состояния счёта и проведения оплаты со стороны клиента.

### 💾 Сохранение данных (Persistent DB)
* **Надёжность при перезапусках:** Баланс и вся история сохраняются в локальный файл `db.json`. При перезапуске или «засыпании» сервера на Render данные не теряются.
* **Единый баланс:** Начальный баланс системы равен `0 ₽` с возможностью пополнения и моментальным обновлением у всех клиентов.

### 🚌 Авто-терминал (Тестовый режим)
* **Автоматическое списание:** Настраиваемый регулярный цикл создания и проведения платежей на выбранный дисплей для демонстраций и нагрузочного тестирования.

### 📜 История и Электронные чеки
* **Полный аудит:** Журнал всех операций с фильтрацией по типам (пополнение / списание) и метками времени.
* **Генерация чеков:** Эндпоинт `/api/receipt/:id` для формирования HTML-чека с функцией скачивания в PDF/PNG.

---

## 🛠 Технологический стек

* **Backend:** Node.js, Express.js
* **Real-time:** Socket.IO (WebSockets)
* **Database:** JSON File Storage (`db.json`, `config.json`)
* **Frontend:** Vanilla JS, HTML5, CSS3
* **QR Generation:** QR Server API

---

## 📡 Основные API Эндпоинты

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/info` | Общая информация (баланс, конфигурация, дисплеи, история) |
| `POST` | `/api/create-transaction` | Создание транзакции и генерация QR-кода |
| `POST` | `/api/process-payment` | Подтверждение и проведение списания |
| `POST` | `/api/topup` | Пополнение единого баланса |
| `GET` | `/api/displays` | Список активных дисплеев покупателя |
| `POST` | `/api/displays/:id/block` | Блокировка / разблокировка дисплея |
| `GET` | `/api/receipt/:id` | Получение печатной формы чека |
