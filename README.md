# 💳 Терминал Оплаты и Баланса (Node.js + Socket.io)

Полноценное интерактивное веб-приложение для POS-терминала с генерацией QR-кодов, звуковыми эффектами (Web Audio API) и мгновенной WebSockets синхронизацией между терминалом и мобильными телефонами клиентов.

---

## 🚀 Особенности и Возможности
1. **Интерфейс POS-терминала (`/`)**:
   - Адаптирован под экраны ПК и кассовых терминалов в тёмном кибер-стиле.
   - Динамический крупный счетчик баланса в реальном времени.
   - **Вкладка пополнения**: удобная нумпад-клавиатура, быстрые кнопки (+100₽, +500₽, +1 000₽, +5 000₽) и приятно звучащие звуковые сигналы (Web Audio API).
   - **Вкладка списания/оплаты**: автоматическая валидация баланса (запрет создания QR при нехватке средств), генерация чистых QR-кодов и онлайн-мониторинг статуса сканирования/оплаты.
   - История проведенных операций с таймстемпами.

2. **Клиентская страница оплаты (`/pay/:id`)**:
   - Красивая мобильная карточка с суммой к оплате.
   - Оплата в 1 клик с отправкой статуса по WebSockets.
   - Анимированный экран чека об успешной оплате.

---

## ⚙️ Настройка и Конфигурация (`config.json`)

В корне проекта расположен файл `config.json`:

```json
{
  "serverIp": "192.168.1.100",
  "port": 3000
}
```

> **Важно**: Все QR-коды и ссылки формируются на основе `serverIp` и `port` из файла `config.json`. 
> Замените `192.168.1.100` на ваш локальный IP-адрес в сети (например, `192.168.0.105` или `localhost` для тестов на одном устройстве), чтобы телефоны в одной Wi-Fi сети могли открывать QR-ссылку.

## 📦 Установка и Запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера
```bash
npm start
```

После запуска в консоли появится адрес для входа:
- **Терминал (ПК)**: `http://localhost:3000`
- **Для смартфонов в Wi-Fi сети**: `http://<serverIp>:<port>`

---

## 🛠 Зависимости
- `express` — серверный фреймворк Node.js
- `socket.io` — дуплексная веб-сокет синхронизация реального времени
- `qrcode` — генерация QR-кодов в виде DataURL
- `cors` — поддержка кросс-доменных запросов

---

## 🔊 Звуковые эффекты
В приложении используется **Web Audio API** (`public/js/audio.js`), который синтезирует звуки прямо в браузере без необходимости загрузки сторонних `.mp3` или `.wav` файлов.
